# Repair CRM

Система для управления ремонтами и заказами в мастерской.

## Технологии

- Python 3.14
- FastAPI
- PostgreSQL
- Docker Compose

## Запуск

```bash
make build
```

После запуска:

- API Gateway: http://localhost:8000
- Swagger Docs: http://localhost:8000/docs

## Остановка

```bash
make down
```
