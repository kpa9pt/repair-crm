# Repair CRM

Система для управления ремонтами и заказами в мастерской мототехники.

---

## 📌 О проекте

Repair CRM — backend-система для обработки заявок на ремонт.  
Проект построен как API-first приложение с минимальной административной панелью для внутреннего использования.

---

## ⚙️ Возможности

- CRUD заявок на ремонт
- Фильтрация и пагинация заявок
- REST API с документацией Swagger
- Административная панель (SQLAdmin, базовый функционал)
- Docker-окружение для разработки и тестирования
- Автоматические тесты (pytest + httpx)

---

## 🧱 Технологии

- Python 3.14
- FastAPI
- PostgreSQL
- SQLAlchemy (async)
- Alembic
- SQLAdmin
- Docker / Docker Compose
- pytest

---

## 🚀 Быстрый старт

```bash
make build
```
## После запуска доступны сервисы:

- API Gateway: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
- Admin panel: http://localhost:8000/admin

---

## 🧪 Тестирование

```bash
make test
```
Тесты запускаются в Docker-окружении с автоматическим поднятием инфраструктуры и пересозданием базы данных.

---

## 🛠️ Основные команды

```bash
make up        # запустить сервисы
make down      # остановить сервисы
make build     # пересобрать и запустить
make test      # запустить тесты
make logs      # посмотреть логи
```

## ⚠️ Известные ограничения

- SQLAdmin имеет ограниченные возможности фильтрации и поиска
- Административный интерфейс не является полноценным продуктом
- Тестовая база данных пересоздается перед запуском тестов
- Отсутствует staging/prod разделение БД (в планах)

---

## 🧭 Архитектура (упрощенно)
- Backend: FastAPI (основной слой системы)
- Database: PostgreSQL
- Admin: SQLAdmin (вспомогательный инструмент)
- Tests: pytest + httpx AsyncClient
- Deployment: Docker Compose
